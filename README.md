# Customer Shopping Behavior Analysis

An end-to-end data analytics project that analyzes customer shopping behavior using **Python, MySQL, and Power BI**. The project focuses on data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard development to uncover actionable business insights.

---

## 📌 Project Overview

This project analyzes customer shopping behavior using transactional data from **3,900 customer purchases** across multiple product categories. The objective is to understand customer spending patterns, purchasing behavior, subscription trends, and product performance to support data-driven business decisions.

---

## 🎯 Business Objectives

- Analyze customer purchasing behavior.
- Identify high-performing products and categories.
- Compare subscriber and non-subscriber spending.
- Segment customers based on purchasing history.
- Evaluate the impact of discounts and shipping methods.
- Build an interactive Power BI dashboard for business insights.
